# Activity 2 — Analyse Excel Marketing Data with the Agent

**Purpose:** Upload a marketing spreadsheet to an AI agent and prompt it to analyse the data, generate charts, and produce a Word (.docx) insights report — and learn how a clear prompt gets a far better result than a vague one.

## What you need

- The **Hermes** agent running on a **MiniMax** model (trainer will share the link/login)
- The mock dataset in this folder: `MOCK-MARKETING-DATA.xlsx` (a printable copy of the same table is in `MOCK-MARKETING-DATA.md`)
- The prompt sheet in this folder: `PROMPTS.md`

**Evidence status: SIM — all data is fictional.** The dataset is a made-up 12-row marketing table for the fictional **Sunset Bay Resort Singapore**.

## Steps

1. Open the **Hermes** agent. Confirm it is set to a **MiniMax** model.
2. Upload `MOCK-MARKETING-DATA.xlsx` to the agent (if upload is not available, paste the table from `MOCK-MARKETING-DATA.md`).
3. **Warm-up — feel the difference a prompt makes.** Send the **BAD prompt** for "top channels by ROI" from `PROMPTS.md`, then the matching **GOOD prompt**. Compare the two answers.
4. **Main task — the full report.** Send the **REPORT prompt** from `PROMPTS.md`. It asks the agent to analyse the data, generate charts (revenue trend by channel, ROI comparison, spend vs revenue), and produce a **.docx report** containing the charts, the analysis and clear recommendations.
5. Download and open the .docx the agent produces. Check it against the **report checklist** in `PROMPTS.md`: are the charts present, do the numbers match the spreadsheet, and are the recommendations backed by figures?
6. Verify at least **two numbers** in the report against the spreadsheet yourself (for example, total Google Ads revenue and the Facebook Ads ROI). Note anything the agent got wrong or made up.

## What you produce

- One before/after pair of answers from the warm-up (bad vs good prompt)
- The agent-generated **.docx report** with charts, analysis and recommendations
- A short note: two numbers you verified, and anything in the report you would not sign off on

## Reflect (Data Privacy / Job Impact / Ethical Concerns / Cyber Security)

- **Data Privacy:** This data is fictional — but if it were real spend and revenue, who should be allowed to upload it to an AI agent?
- **Job Impact:** How long would this analysis-plus-report take you by hand? What is the analyst freed to do instead?
- **Ethical Concerns:** If a chart or ROI figure in the report is wrong, who checks it before it reaches a manager?
- **Cyber Security:** Where does the uploaded file go, and could it be seen by others?
