# Activity 2 — Analyse Excel Marketing Data with the Agent

**Purpose:** Use an AI agent to analyse a marketing spreadsheet, and learn how a clear prompt gets a far better answer than a vague one.

## What you need

- The **Hermes** agent running on a **MiniMax** model (trainer will share the link/login)
- The mock dataset in this folder: `MOCK-MARKETING-DATA.md` (or the `.xlsx` your trainer supplies)
- The prompt sheet in this folder: `PROMPTS.md`

**Evidence status: SIM — all data is fictional.** The dataset is a made-up 12-row marketing table for the fictional **Sunset Bay Resort Singapore**.

## Steps

1. Open the **Hermes** agent. Confirm it is set to a **MiniMax** model.
2. Give the agent the data: either paste the table from `MOCK-MARKETING-DATA.md`, or upload the `.xlsx` the trainer provides.
3. Send the **BAD prompt** for "top channels by ROI" from `PROMPTS.md`. Note how vague or generic the answer is.
4. Now send the matching **GOOD prompt** (which names the columns, the metric and the format you want). Compare the two answers.
5. Repeat the BAD-then-GOOD comparison for at least **two more tasks** from `PROMPTS.md` (month-on-month trend, an underperformer to cut, an exec summary).
6. Write down, in one line each, **what the good prompt added** that improved the answer (for example: named columns, asked for a table, defined ROI).

## What you produce

- One before/after pair of answers for at least three tasks
- A short note listing what made each GOOD prompt work
- One recommended channel to cut, with the number that supports it

## Reflect (Data Privacy / Job Impact / Ethical Concerns / Cyber Security)

- **Data Privacy:** This data is fictional — but if it were real spend and revenue, who should be allowed to upload it to an AI agent?
- **Job Impact:** How long would this analysis take you by hand? What is the analyst freed to do instead?
- **Ethical Concerns:** If the agent's ROI figure is wrong, who checks it before it reaches a manager?
- **Cyber Security:** Where does the uploaded file go, and could it be seen by others?
