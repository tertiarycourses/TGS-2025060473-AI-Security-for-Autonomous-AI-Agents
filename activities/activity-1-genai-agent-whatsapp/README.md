# Activity 1 — Talk to an AI Agent, Then Reflect

**Purpose:** Experience a real customer-service AI agent on WhatsApp, test where it helps and where it stops, then reflect on the risks and opportunities.

## What you need

- Your own mobile phone with WhatsApp
- **TIA Support** on WhatsApp: **+65 8866 6375** (powered by OpenClaw)
- The class **Pinboard**: https://alfredang.github.io/pinboard/
- The prompt sheet in this folder: `PROMPTS.md`

**Evidence status: SIM — all data is fictional.** Do not send any real customer, guest or personal data. Use only the made-up examples provided.

## Steps

1. Save **+65 8866 6375** as a contact and open a WhatsApp chat with **TIA Support**.
2. Send a short greeting so the agent introduces itself. Note how it describes what it can do.
3. Pick **one main task** from `PROMPTS.md` (for example, drafting a polite reply to a guest asking for a late 2 pm check-out) and send it. Read the reply carefully.
4. Send **one follow-up** that changes the request slightly (for example, "make it warmer and add a small apology"). See how well the agent keeps the context.
5. Send the **out-of-scope / tricky prompt** from `PROMPTS.md` and watch how the agent responds. Does it refuse, guess, or ask for more information?
6. Open the **Pinboard** and post **one short reflection per theme** — four notes in total, each starting with the theme name:
   - **Data Privacy** — what data did it ask for or assume?
   - **Job Impact** — what part of a real job did it speed up?
   - **Ethical Concerns** — where could it mislead a guest?
   - **Cyber Security** — how could someone misuse this channel?

## What you produce

- One completed WhatsApp conversation (main task + follow-up + tricky prompt)
- Four Pinboard notes, one for each theme, each 1–2 sentences

## Reflect (Data Privacy / Job Impact / Ethical Concerns / Cyber Security)

- **Data Privacy:** Would you be comfortable if a real guest's name and booking went through this chat? Why or why not?
- **Job Impact:** Which task took the agent seconds that would take a person minutes? What does the person do instead now?
- **Ethical Concerns:** When the agent was unsure, did it admit it, or answer confidently anyway?
- **Cyber Security:** If an attacker had this number, what harmful requests might they try?
