# Activity 3 — Build an Animated PowerPoint with the Agent

**Purpose:** Turn a written script into a short animated slide deck using the AI agent, and see how a detailed prompt beats a vague one.

## What you need

- The **Hermes** agent on a **MiniMax** model (trainer will share the link/login)
- An **Envato** PowerPoint template — browse: elements.envato.com/presentation-templates/compatible-with-powerpoint
- The script in this folder: `SCRIPT.md`
- The prompt sheet in this folder: `PROMPTS.md`

**Evidence status: SIM — all data is fictional.** The script describes a made-up marketing plan for the fictional **Sunset Bay Resort**.

## Steps

1. Open the **Hermes** agent (MiniMax model).
2. Choose one **Envato** PowerPoint template and note its name (for example, "Aurora Business"). You will name it in your prompt.
3. Give the agent the content from `SCRIPT.md`.
4. Send the **vague prompt** from `PROMPTS.md` first ("make me a presentation"). Look at what you get.
5. Now send the **detailed prompt** — it names the template, asks for 5 slides, title animations, a summary slide and a brand tone. Compare the two decks.
6. Review the animated deck: does it match the script? Are the bullets readable? Is the summary slide clear?
7. Note **three things** the detailed prompt controlled that the vague one did not.

## What you produce

- One short animated deck (5 slides) based on `SCRIPT.md`
- A note comparing the vague-prompt deck with the detailed-prompt deck
- A list of the three improvements the detailed prompt gave you

## Reflect (Data Privacy / Job Impact / Ethical Concerns / Cyber Security)

- **Data Privacy:** If real numbers went into these slides, where would the finished file be stored and shared?
- **Job Impact:** How long would this deck take to build by hand? What does the designer now spend time on?
- **Ethical Concerns:** If the agent invents a statistic to fill a slide, who catches it before the meeting?
- **Cyber Security:** Could a downloaded template or generated file carry anything unexpected? Who approves what you download?
