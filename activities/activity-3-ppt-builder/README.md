# Activity 3 — Create and Redesign a PowerPoint with the Agent

**Purpose:** Have the AI agent build a complete slide deck from one detailed prompt, then upload an image template and have the agent redesign the whole deck to match it — seeing how an agent iterates on its own output.

## What you need

- The **Hermes** agent on a **MiniMax** model (trainer will share the link/login)
- The prompt sheet in this folder: `PROMPTS.md`
- The image template in this folder: `new-template.avif` (dark AI-security theme)
- Worked examples in this folder: `AI-Security-for-AI-Agents.pptx` (first version) and `AI-Security-for-AI-Agents-Redesigned.pptx` (after the template redesign)

**Evidence status: SIM — the decks are generated teaching output.** No real company data is involved.

## Steps

1. Open the **Hermes** agent (MiniMax model).
2. Send the **CREATE prompt** from `PROMPTS.md` — it asks for a **10-slide PowerPoint on AI Security for AI Agents** with speaker notes, returned as a downloadable file.
3. When the deck is ready, **download it and save it to your Downloads folder**.
4. **Upload the image template** `new-template.avif` from this folder into the chat.
5. Send the **REDESIGN prompt** from `PROMPTS.md` — it asks the agent to restyle every slide using the uploaded image as the visual theme, keeping the content and speaker notes unchanged.
6. Download the redesigned deck to your **Downloads folder** and open both files side by side.
7. Note **three things** the template redesign changed (colours, imagery, layout, mood).

## What you produce

- Two decks in your Downloads folder: the original 10-slide deck and the template-redesigned version
- A note listing the three biggest changes the image template drove

## Reflect (Data Privacy / Job Impact / Ethical Concerns / Cyber Security)

- **Data Privacy:** The deck lands in your Downloads folder. If it held real client content, who else could reach that file?
- **Job Impact:** The agent produced and restyled 10 slides in minutes. What does the designer now spend time on?
- **Ethical Concerns:** The agent wrote the security content itself. Who checks it is accurate before it is taught or presented?
- **Cyber Security:** You uploaded an image into the agent. What else could a file upload carry, and who approves what gets uploaded?
